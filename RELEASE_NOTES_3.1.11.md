# SBC5 Control Center Integration 3.1.11

## English

This release keeps the HACS integration version aligned with SBC5 Control Center 3.1.11.

- No sensor, coordinator or polling behavior changes.
- AI Cooling v5.1 transient-response learning runs in the SBC5 application runtime.
- The integration continues to expose the existing relay/runtime data to Home Assistant.
- No Raspberry Pi host restart is required by this integration release.

## Polski

To wydanie synchronizuje wersję integracji HACS z SBC5 Control Center 3.1.11.

- Brak zmian w sensorach, koordynatorze i częstotliwości pollingu.
- AI Cooling v5.1 z uczeniem odpowiedzi przejściowej działa w runtime aplikacji SBC5.
- Integracja nadal udostępnia do Home Assistant istniejące dane relay/runtime.
- To wydanie integracji nie wymaga restartu hosta Raspberry Pi.
