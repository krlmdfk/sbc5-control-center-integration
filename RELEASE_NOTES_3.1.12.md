# SBC5 Control Center Integration 3.1.12

## English

This release keeps the HACS integration version aligned with SBC5 Control Center 3.1.12.

- No sensor, coordinator or polling behavior changes.
- SBC5 Control Center 3.1.12 exposes AI Cooling v5.1 transient confidence, sample count and support through the existing transfer diagnostics path.
- The integration continues to expose the existing relay/runtime data to Home Assistant without additional polling.
- No Raspberry Pi host restart is required by this integration release.

## Polski

To wydanie synchronizuje wersję integracji HACS z SBC5 Control Center 3.1.12.

- Brak zmian w sensorach, koordynatorze i częstotliwości pollingu.
- SBC5 Control Center 3.1.12 udostępnia pewność transient, liczbę próbek i support AI Cooling v5.1 przez istniejącą ścieżkę diagnostyki transferu.
- Integracja nadal udostępnia istniejące dane relay/runtime do Home Assistant bez dodatkowego pollingu.
- To wydanie integracji nie wymaga restartu hosta Raspberry Pi.
