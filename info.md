# SBC5 Control Center

Native Home Assistant integration for the SBC5 Control Center App on Raspberry Pi 5.

It exposes SBC5 telemetry, diagnostics, device identity, update state and Restart Manager entities in Home Assistant.

## Installation

Add this repository to HACS as a **Custom repository** of type **Integration**:

`https://github.com/krlmdfk/sbc5-control-center-integration`

Then install **SBC5 Control Center** and restart Home Assistant when requested.

The SBC5 Control Center App/runtime must already be installed and running on the host.
