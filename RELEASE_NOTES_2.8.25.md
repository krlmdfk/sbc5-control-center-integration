# SBC5 Control Center Integration 2.8.25

**English** · [Polski](#polski)

## English

First public GitHub/HACS-ready release of the native Home Assistant integration for SBC5 Control Center.

### Included

- native SBC5 device and entity model for Home Assistant;
- Raspberry Pi device identity and firmware diagnostics;
- CPU, GPU/V3D/ISP, cooling, AI and update telemetry;
- Restart Manager and Repairs integration;
- update entity support;
- Polish and English translations;
- HACS ownership marker preventing the SBC5 App from overwriting an integration managed by HACS;
- HACS, Hassfest, Python and JSON validation workflow.

### Requirements

- Home Assistant 2026.10.1 or newer;
- SBC5 Control Center App/runtime already installed and running on Raspberry Pi 5.

Main project / required App: https://github.com/krlmdfk/sbc5-control-center

### Upgrade notes

Installing or updating this integration requires a Home Assistant restart. A Raspberry Pi host restart is not required by the integration update itself.

## Polski

Pierwsze publiczne wydanie natywnej integracji Home Assistant dla SBC5 Control Center, przygotowane do instalacji przez GitHub/HACS.

### Zawartość

- natywny model urządzenia i encji SBC5 dla Home Assistant;
- identyfikacja urządzenia Raspberry Pi i diagnostyka firmware;
- telemetria CPU, GPU/V3D/ISP, chłodzenia, AI i aktualizacji;
- integracja Restart Managera i Repairs;
- obsługa encji aktualizacji;
- tłumaczenia polskie i angielskie;
- znacznik własności HACS zapobiegający nadpisaniu przez aplikację SBC5 integracji zarządzanej przez HACS;
- workflow walidacji HACS, Hassfest, Python i JSON.

### Wymagania

- Home Assistant 2026.10.1 lub nowszy;
- aplikacja/runtime SBC5 Control Center zainstalowana i uruchomiona na Raspberry Pi 5.

Główny projekt / wymagana aplikacja: https://github.com/krlmdfk/sbc5-control-center

### Informacje o aktualizacji

Instalacja lub aktualizacja tej integracji wymaga ponownego uruchomienia Home Assistant. Sama aktualizacja integracji nie wymaga restartu hosta Raspberry Pi.
