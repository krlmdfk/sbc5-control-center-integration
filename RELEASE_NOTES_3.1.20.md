# SBC5 Control Center Integration 3.1.20

## English

This maintenance release keeps HACS integration version parity with SBC5 Control Center 3.1.20.

- No integration polling or control behavior changes.
- Companion application 3.1.20 fixes the AI Cooling runtime layer chain so Thermal Predictor updates are not bypassed.
- Dashboard history improvements are delivered by the application package.
- Restart Home Assistant Core after updating the HACS integration.

## Polski

To wydanie techniczne utrzymuje zgodność wersji integracji HACS z SBC5 Control Center 3.1.20.

- Bez zmian w sposobie odpytywania i sterowania przez integrację.
- Aplikacja 3.1.20 naprawia łańcuch warstw runtime AI Cooling, aby aktualizacje Thermal Predictora nie były pomijane.
- Ulepszenia wykresów historii są dostarczane przez pakiet aplikacji.
- Po aktualizacji integracji HACS należy zrestartować Home Assistant Core.
