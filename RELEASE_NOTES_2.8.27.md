# SBC5 Control Center Integration 2.8.27

## English

Dependency documentation release: clearly documents the required SBC5 App/runtime and the Mushroom, card-mod and ApexCharts Card frontend dependencies for the complete Lovelace dashboard. No cooling, AI, CPU/GPU or boot-configuration logic changes.

### Requirements

- Home Assistant >= 2026.10.1
- SBC5 Control Center App/runtime installed and running on Raspberry Pi 5
- for the complete Lovelace dashboard: **Mushroom**, **card-mod**, **ApexCharts Card**

Restart Home Assistant after installation/update when requested. A Raspberry Pi host restart is not required by this integration update itself.

## Polski

- Home Assistant >= 2026.10.1
