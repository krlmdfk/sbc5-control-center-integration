# SBC5 Control Center Integration 3.1.22

## English

Hotfix companion release for SBC5 Control Center App 3.1.22.

- Keeps HACS integration version parity with App 3.1.22.
- App 3.1.22 fixes the container image build path for AI Cooling v5.2 introduced in 3.1.21.
- No telemetry or polling behavior changes in the integration.
- Restart Home Assistant Core after updating the HACS integration.

## Polski

Wydanie towarzyszące hotfix dla SBC5 Control Center App 3.1.22.

- Utrzymuje zgodność wersji integracji HACS z aplikacją 3.1.22.
- Aplikacja 3.1.22 naprawia ścieżkę budowania obrazu kontenera dla AI Cooling v5.2 wprowadzoną w 3.1.21.
- Integracja nie zmienia sposobu odpytywania ani telemetrii.
- Po aktualizacji integracji HACS należy zrestartować Home Assistant Core.
