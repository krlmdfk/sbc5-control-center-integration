# SBC5 Control Center Integration 3.2.0 — Global Community Edition candidate

## English
- Companion HACS integration prepared for SBC5 Control Center App/runtime 3.2.0 (Raspberry Pi 5, Home Assistant OS).
- The App is available internationally through its community Apps repository, not yet the official Home Assistant App catalog.
- Security disclosure: the App requires broad host privileges and Protection Mode disabled. See the main project permission audit.
- No HACS entity model, polling, Repairs or fan/PWM control changes.
- This is a **release candidate** and must not be published before hardware validation and matched App 3.2.0 release.

## Polski
- Integracja HACS zgodna z kandydatem SBC5 Control Center App 3.2.0 (Raspberry Pi 5, Home Assistant OS).
- Aplikacja dostępna globalnie przez repozytorium społecznościowe Apps, lecz nie w oficjalnym katalogu aplikacji Home Assistant.
- Ostrzeżenie: aplikacja wymaga szerokich uprawnień hosta i wyłączonego Protection Mode. Szczegóły w audycie uprawnień projektu głównego.
- Bez zmian encji, odpytywania, Repairs i PWM.
- **Kandydat wydania:** publikacja dopiero po testach sprzętowych i synchronizacji App 3.2.0.
