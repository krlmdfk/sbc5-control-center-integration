# SBC5 Control Center Integration 3.1.1

## English

### Highlights

- Aligned with SBC5 Control Center App/runtime and Card UI **3.1.1**.
- Integration behavior remains unchanged from 3.1.0.
- App/package 3.1.1 adds responsive YAML/Lovelace AI Thermal Predictor tiles for +30 s, +60 s, +120 s and predictor confidence.
- HACS ownership protection remains active through `.hacs_managed`.

### Requirements

- SBC5 Control Center App/runtime 3.1.1 installed and running
- Home Assistant Core >= 2026.10.1
- HACS-managed installation
- Raspberry Pi 5

### Upgrade notes

- Update the App through the Home Assistant Apps Store / configured SBC5 repository.
- Update this companion integration through HACS.
- Existing integration configuration is preserved during a normal HACS upgrade.
- Restart Home Assistant only when requested by HACS.
- No Raspberry Pi host restart is required by this release.

## Polski

### Najważniejsze zmiany

- Wyrównanie z aplikacją/runtime i Card UI SBC5 Control Center **3.1.1**.
- Zachowanie integracji pozostaje bez zmian względem 3.1.0.
- App/package 3.1.1 dodaje responsywne kafelki YAML/Lovelace AI Thermal Predictor dla +30 s, +60 s, +120 s i pewności predyktora.

### Wymagania

- Zainstalowana i uruchomiona aplikacja/runtime SBC5 Control Center 3.1.1
- Home Assistant Core >= 2026.10.1

- Raspberry Pi 5

### Informacje o aktualizacji

- Aplikację aktualizuj przez Sklep Apps Home Assistant / skonfigurowane repozytorium SBC5.
- Integrację towarzyszącą aktualizuj przez HACS.
- Istniejąca konfiguracja integracji jest zachowywana podczas standardowej aktualizacji HACS.
- Uruchom ponownie Home Assistant tylko wtedy, gdy HACS tego wymaga.
- To wydanie nie wymaga restartu hosta Raspberry Pi.
