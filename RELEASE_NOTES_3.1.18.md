# SBC5 Control Center Integration 3.1.18

## English

- Aligns the HACS integration version with SBC5 Control Center App 3.1.18.
- Keeps `SBC5 Ethernet Health`, `SBC5 Ethernet Link Flaps` and `SBC5 Ethernet EEE Status` entity compatibility unchanged from 3.1.17.
- Companion App 3.1.18 fixes persistent Ethernet EEE state across host reboots and the false custom1 `pending_host_reboot` status.
- No additional Home Assistant network polling is introduced.

## Polski

- Synchronizuje wersję integracji HACS z aplikacją SBC5 Control Center 3.1.18.
- Zachowuje bez zmian zgodność encji `SBC5 Ethernet Health`, `SBC5 Ethernet Link Flaps` oraz `SBC5 Ethernet EEE Status` względem 3.1.17.
- Aplikacja 3.1.18 naprawia trwałość ustawienia Ethernet EEE po restartach hosta oraz fałszywy status custom1 `pending_host_reboot`.
- Nie dodaje dodatkowego odpytywania sieci przez Home Assistant.
