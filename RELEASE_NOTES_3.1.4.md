# SBC5 Control Center Integration 3.1.4

## English

### Highlights
- Adds native AI Thermal Predictor quality state alongside the existing forecast/error diagnostics.
- Aligns HACS metadata and current README information with App/runtime 3.1.4.
- No additional polling; the existing 15-second coordinator and AI runtime relay are reused.

### Upgrade notes
- Update SBC5 Control Center App/runtime to 3.1.4 through the Home Assistant Apps Store / configured SBC5 repository.
- Update this companion integration through HACS.
- Restart Home Assistant only when HACS requests it.
- No Raspberry Pi host restart is required.
