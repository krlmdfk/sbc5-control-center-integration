# SBC5 Control Center Integration 3.1.29

## English

- Version parity release for SBC5 Control Center 3.1.29.
- No integration entity-model or polling-cadence changes are introduced in this companion release.
- Companion release for the application thermal-control stability update: raw-versus-control temperature separation, median-of-3 spike filtering, asymmetric EWMA smoothing, 30/120-second trend confirmation, PWM direction hysteresis and Thermal Predictor forecast confirmation.
- Existing Home Assistant entities remain compatible with the 3.1.29 App runtime and continue to consume the canonical SBC5 relay state.

## Polski

- Wydanie zgodności wersji dla SBC5 Control Center 3.1.29.
- To wydanie towarzyszące nie zmienia modelu encji integracji ani częstotliwości odpytywania.
- Towarzyszy aktualizacji stabilności sterowania termicznego aplikacji: rozdzieleniu temperatury surowej i sterującej, filtrowaniu pików medianą z 3 próbek, asymetrycznemu EWMA, potwierdzaniu trendu 30/120 s, bezwładności kierunku PWM oraz potwierdzaniu prognoz Thermal Predictora.
- Istniejące encje Home Assistant pozostają zgodne z runtime aplikacji 3.1.29 i nadal korzystają z kanonicznego stanu relay SBC5.
