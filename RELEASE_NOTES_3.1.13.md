# SBC5 Control Center Integration 3.1.13

## English

This release keeps the HACS integration version aligned with SBC5 Control Center 3.1.13.

- No sensor, coordinator or polling behavior changes.
- SBC5 Control Center 3.1.13 hardens AI Cooling diagnostics so sparse workload buckets report direct confidence only from qualified direct evidence.
- Global, effective and transient learning remain unchanged in the App/runtime.
- The integration continues to expose the existing relay/runtime data to Home Assistant without additional polling.
- No Raspberry Pi host restart is required by this integration release.

## Polski

To wydanie synchronizuje wersję integracji HACS z SBC5 Control Center 3.1.13.

- Brak zmian w sensorach, koordynatorze i częstotliwości pollingu.
- SBC5 Control Center 3.1.13 utwardza diagnostykę AI Cooling: rzadkie buckety pokazują direct confidence wyłącznie na podstawie kwalifikowanych danych bezpośrednich.
- Uczenie global, effective i transient w App/runtime pozostaje bez zmian.
- Integracja nadal udostępnia istniejące dane relay/runtime do Home Assistant bez dodatkowego pollingu.
- To wydanie integracji nie wymaga restartu hosta Raspberry Pi.
