# SBC5 Control Center Integration 3.1.21

## English

This companion release keeps HACS integration version parity with SBC5 Control Center 3.1.21.

- Synchronizes the integration metadata with App 3.1.21.
- App 3.1.21 introduces Thermal Predictor guided assist through the existing guarded AI Cooling/Adaptive PWM path.
- No new polling loop is added by the integration.
- Thermal Predictor diagnostics remain available through the existing SBC5 runtime telemetry.
- Restart Home Assistant Core after updating the HACS integration.

## Polski

To wydanie towarzyszące utrzymuje zgodność wersji integracji HACS z SBC5 Control Center 3.1.21.

- Synchronizuje metadane integracji z aplikacją 3.1.21.
- Aplikacja 3.1.21 wprowadza Thermal Predictor guided assist poprzez istniejącą, zabezpieczoną ścieżkę AI Cooling / Adaptive PWM.
- Integracja nie dodaje nowej pętli odpytywania.
- Diagnostyka Thermal Predictora pozostaje dostępna przez istniejącą telemetrię SBC5.
- Po aktualizacji integracji HACS należy zrestartować Home Assistant Core.
